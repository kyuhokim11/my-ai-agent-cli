# New Project Entry Policy

이 모드는 사용자가 CLI에서 신규 프로젝트를 선택했을 때 적용된다. 이미 요청과 대화에서 확인되는 목적이나 조건을 다시 묻지 않는다.

1. 구현 전에 목적, 사용자, 성공 조건과 이번 작업 범위를 명확히 한다.
2. 요청되지 않은 프레임워크, 라이브러리, 계층 또는 확장 가능성을 미리 추가하지 않는다.
3. 플랫폼 기본 기능, 언어 표준 기능, 이미 선택된 도구 순서로 해결 가능성을 검토한다.
4. 최초 구조도 이후 변경 비용이 가장 작은 최소 단위로 시작한다.
5. 아직 결정되지 않은 API, 환경 변수와 배포 조건을 임의로 확정하지 않는다.
