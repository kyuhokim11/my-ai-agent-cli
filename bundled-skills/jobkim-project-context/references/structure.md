# 기록 구조 선택

파일명보다 역할과 탐색 경로를 유지한다. 다음은 기존 체계가 없을 때의 예시이며 설치 시 자동 생성할 목록이 아니다.

```text
README.md                     # 목표·범위와 기록 안내 링크
docs/context/index.md          # 역할별 원본 위치, 활성 작업 링크
docs/work/<task-id>.md         # 재개할 작업의 상태·변화·검증·다음 행동
docs/context/architecture.md   # 구조 설명이 필요한 경우만
docs/decisions/<decision-id>.md # 중요한 결정이 있는 경우만
```

작은 프로젝트는 README의 안내 절과 작업 문서 하나로 시작할 수 있다. 기존 프로젝트는 기존 설계·작업 문서를 사용한다. 여러 모듈이면 전체 안내에서 범위별 안내로 연결하고 공통 원칙은 복제하지 않는다.

기록 안내에는 다음 역할의 실제 파일·절 링크와 적용 범위를 적는다.

| 역할 | 위치에 담을 정보 |
|---|---|
| 목표·범위 | 승인된 목적, 성공 기준, 제외 범위 |
| 구조·흐름 | 실제 구성요소와 책임, 관련 흐름 |
| 활성 작업 | 현재 작업 원본으로 가는 링크 |
| 결정 | 중요한 선택의 이유와 대체 관계 |

아직 불필요한 역할은 필요 시 도입한다고 표시하고 빈 파일을 만들지 않는다. 안내 자체의 위치는 README 또는 범위별 에이전트 지침에서 찾을 수 있게 한다. 외부 이슈가 상태 원본이면 링크로 참조하고 별도 상태 복사본을 유지하지 않는다.

승인된 구조 변경 시 안내의 역할 대응과 관련 링크를 함께 갱신한다. 관련 작업 이력에 변경 시점·이유·이전/새 위치를 남긴다. 다음 세션도 실제 위치를 따라가도록 하고, 설치 기본 경로로 되돌리지 않는다.
